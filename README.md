## Repository Structure

| Path | Description |
|------|-------------|
| `text reportbuilder-repository/` | Root directory |
| `backend/` | Spring Boot Java Engine (REST APIs & JPA Schema) |
| `backend/mvn/` | Maven files |
| `backend/src/` | Database packages, entities, and controllers |
| `backend/mvnw` | Maven wrapper for Unix/macOS |
| `backend/mvnw.cmd` | Maven wrapper for Windows |
| `backend/pom.xml` | Backend dependency configurations |
| `frontend/` | Angular Frontend (Web UI Component Canvas) |
| `frontend/src/` | HTML templates, CSS styles, and TypeScript logic |
| `frontend/angular.json` | Angular CLI workspace configurations |
| `frontend/package.json` | Frontend third-party libraries |
| `frontend/tsconfig.json` | TypeScript compiler configurations |
| `.gitignore` | Global workspace ignore boundaries |
| `.prettierrc` | Shared code-formatting configurations |
| `README.md` | This documentation |
